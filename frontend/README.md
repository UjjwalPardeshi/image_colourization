# AI Colorizer Frontend

A premium, high-performance web interface for the AI Image Colorization service.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the app:
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion** (Animations)
- **Axios** (API Requests)

## 🎨 UI Features
- Glassmorphism design
- Ambient background animations
- Drag-and-drop file upload
- Before/After comparison slider
- Fully responsive layout
